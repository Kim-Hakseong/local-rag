# spec/samples_README.md — GV-2용 실물 문서 5종 (인간 제공)

`samples\` 폴더에 아래 구성으로 투입한다. 회사 기밀이 아닌, 표가 포함된 실사용 성격의 문서를 고를 것.
(공공기관 배포 HWP, 개인 작성 문서, 규격/양식류 등. 저장소 커밋 금지 — .gitignore 처리됨)

| # | 요건 | 목적 |
|---|---|---|
| 1 | HWP 5.x, 표 3개 이상 포함 | 표 셀 값 1:1 대조 (핵심) |
| 2 | HWPX (한컴 2020+) | 최신 포맷 경로 검증 |
| 3 | 구버전 HWP (가능하면 2000년대~2010년대 초) | 레거시 경로 검증. 못 구하면 "미확보"로 기록하고 스킵 |
| 4 | 배포용/열람제한 HWP | 순수 JS 복호화 범위 확인. 못 구하면 스킵 |
| 5 | 암호(비밀번호) 걸린 HWP | GV-3 실패 분류 검증용 (변환 성공이 아니라 **깨끗한 실패**가 합격) |

- 3, 4번은 미확보 시 스킵 가능하나 DECISIONS.md에 명시.
